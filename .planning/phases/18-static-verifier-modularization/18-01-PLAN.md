| Boundary | Description |
| --- | --- |
| checked-in domain helpers -> verifier modules | Route/content/metadata helpers provide expected values consumed by the static verifier. |
| generated `.output/public` -> verifier assertions | Static HTML, CSS, sitemap, robots, and image assets are untrusted generated output until verified. |
| verifier modules -> Vitest imports | Focused tests import helper modules and must not trigger generated-output reads at import time. |
| verifier success output -> release decision | Human release decisions inspect verifier output and evidence wording. |
| metadata URLs -> local output assets | Canonical Open Graph/Twitter image URLs must map to the checked-in static social asset. |
