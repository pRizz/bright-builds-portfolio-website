<threat_model>
ASVS level: 1
Block on: high

Threats:
- Hidden content leakage through topic routes. Mitigation: route pages must consume `publicTopics()` and `maybePublicTopicBySlug()` only; no route file may read raw curated project, writing, or theme arrays for topic membership.
- Unsupported public route exposure. Mitigation: `topicDetailRoutes()` must derive from `publicTopics()`, not `curatedTopics`, and unknown topic slugs must not be in `prerenderRoutes`.
- Runtime content-fetch regression. Mitigation: topic routes must render from checked-in domain modules only and must not call `fetch`, GitHub, CMS, search, feed, or network APIs.
- Accessibility regression from linked cards/chips. Mitigation: use normal anchors, existing focus classes, pre-hydration HTML, and existing browser axe/layout checks.
</threat_model>
