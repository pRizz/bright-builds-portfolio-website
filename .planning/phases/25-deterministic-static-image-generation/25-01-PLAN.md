<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| checked-in route content -> generated public PNGs | Public project, writing, theme, and index route text becomes share-card image content. |
| social preview target asset path -> local filesystem | `/social/generated/...` web paths become writable files under `public/social/generated/`. |
| SVG template text -> resvg renderer | Curated copy is interpolated into XML/SVG and then rasterized by a native dependency. |
| generated PNGs + manifest -> static deploy artifact | Checked-in files are copied into `.output/public` and later crawlers can request them. |
| maintainer CLI -> local environment | The generator runs on a developer or clean-builder machine but must not read secrets, make network requests, use runtime services, or add runtime endpoints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-25-01 | Tampering | `scripts/social-previews/paths.ts` and generator cleanup | mitigate | Resolve target paths under `public/social/generated/` with a `relative()` guard; reject fallback, remote, traversal, sibling, and non-PNG paths; test that `public/social/bright-builds-og.png` survives generation. |
| T-25-02 | Information Disclosure | `scripts/generate-social-previews.ts` target inventory | mitigate | Consume only `socialPreviewTargets()` and run `validateSocialPreviewTargets()` before rendering or cleanup so hidden/draft/non-public records cannot become checked-in PNGs. |
| T-25-03 | Tampering | `scripts/social-previews/template.ts` SVG interpolation | mitigate | Centralize XML escaping for text and attributes; unit-test `&`, `<`, `>`, `"`, and `'`; prohibit raw route text interpolation in attributes. |
| T-25-04 | Repudiation | `public/social/generated/manifest.json` | mitigate | Write a sorted timestamp-free manifest with `sourceFingerprint`, `byteSize`, and SHA-256 file checksum for every generated preview; check mode compares rerendered bytes to files and manifest. |
| T-25-05 | Denial of Service | generated PNG size and renderer output | mitigate | Enforce `250 * 1024` bytes per PNG, 1200x630 dimensions, blank-image detection, and nonzero PNG buffers in `verify:social-previews`. |
| T-25-06 | Information Disclosure | generator/runtime environment | mitigate | Generator/template/render code must not read `process.env`, call `fetch`, include `http`/`https` asset URLs, use GitHub APIs, use clocks, or use randomness; acceptance criteria include `rg` scope guards. |
| T-25-07 | Tampering / Availability | `@resvg/resvg-js` native dependency | mitigate | Pin `@resvg/resvg-js@2.6.2`, commit `bun.lock`, run an early render smoke test, and keep generated PNGs checked in so static deployment does not rasterize at visitor runtime. |
| T-25-08 | Spoofing | route card brand/copy | mitigate | Template renders route-specific target copy and low-intrusion Bright Builds/Peter footer only; generic OpenLinks CTA text is not added except where route data itself is OpenLinks-specific. |
| T-25-09 | Elevation of Privilege | runtime application surface | accept | Phase 25 adds no API route, dynamic OG endpoint, server function, auth, database, visitor runtime code, or external service integration. This phase should not read secrets, make network requests during generation/check, or add runtime endpoints. |
</threat_model>
