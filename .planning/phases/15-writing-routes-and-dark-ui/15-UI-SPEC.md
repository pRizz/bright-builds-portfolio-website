# Phase 15 - UI Design Contract

> Visual and interaction contract for Writing Routes and Dark UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope Locks

Phase 15 owns the public writing index, public writing detail route UI, unknown-writing fallback UI, and related-writing links on selected project detail pages.

In scope:

- Add `/writing` as a first-class top-level route and primary navigation item after `Projects` and before `Contact`.
- Add static `/writing/{slug}` detail pages for public writing entries only.
- Render writing body sections directly from typed `sections`; do not add Markdown, MDX, CMS, parser, runtime API, RSS, search, comments, newsletter, pagination, or tag archive UI.
- Show related selected project links on writing detail pages through `relatedProjectDetailPageProjects(entry)`.
- Show related writing on selected project detail pages only when public writing references that project, derived from writing data.

Out of scope:

- Phase 16 owns writing-specific detail metadata, JSON-LD, sitemap assertions, and social sharing polish.
- Phase 17 owns release-readiness documentation, release evidence labels, and aggregate release-gate expansion.
- Project index writing badges are not required in this phase.

Design system notes:

- Mystic UI is already pinned in `package.json` to `github:pRizz/mystic-ui#d36017757708ed01ef2b3b47beb14f294726411c`.
- Do not introduce light-first utilities such as `bg-white`, `bg-stone-50`, or `text-zinc-950`.
- Do not use nested cards. Cards are allowed for repeated writing items, related project items, related writing items, and fallback states.
- Keep card and panel radius at 8px. Chips may keep the existing 6px radius.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline label gaps, small metadata gaps |
| sm | 8px | Chip rows, compact link rows, card internal small gaps |
| md | 16px | Default grid gaps, paragraph-to-meta spacing |
| lg | 24px | Card padding, panel padding, writing section block gaps |
| xl | 32px | Detail layout gaps, index section gaps |
| 2xl | 48px | Page top/bottom rhythm through existing shell spacing |
| 3xl | 64px | Major page-level separation only when inherited from existing route patterns |

Exceptions:

- Reuse existing shell horizontal padding of 20px (`px-5`) from `.site-main` and `.site-header-inner`; do not add a competing page gutter.
- All clickable links and buttons must keep at least a 44px touch target using existing `min-h-11` and `min-w-11` patterns.
- Existing `scroll-margin-top: 64px` on anchored cards remains valid for sticky-header offset.

## Typography

Use exactly these four sizes and two weights for Phase 15 UI:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.25 |
| Display | 36px | 600 | 1.15 |

Typography rules:

- Use `.page-title` for `/writing` and writing detail H1 text.
- Use `.section-title`, `.card-title`, and `h2` for writing body section headings.
- Use `.lead`, `.body-copy`, `.card-copy`, and `.story-stack p` for readable body copy.
- Do not add new font families, negative letter spacing, viewport-scaled font sizes, or font weights beyond 400 and 600.
- Long titles, URLs, tags, and link labels must use `min-width: 0` plus `overflow-wrap: anywhere` or equivalent existing classes.

|------|-------|-------|

| Secondary (30%) | `#18181b` over `#0d1117` | Cards, nav, panels, repeated writing items, detail asides |
| Accent (10%) | `#6ee7b7` | Primary CTA fill, selected labels, chips/pills, section labels, hover borders, text links, selection background |
| Focus | `#67e8f9` | Focus-visible rings only |
| Warning/callout | `#fcd34d` / amber border | Writing callout blocks and non-destructive notice panels only |
| Destructive | none | No destructive actions exist in Phase 15 |

Accent reserved for:

- `Browse writing`, `Read note`, and `Read essay` action states.
- Writing kind/status pills and topic/tag chips.
- Section labels such as `Published`, `Updated`, `Topics`, and `Related projects`.
- Link text, hover borders, and subtle reactive card glow.
- Text selection background.

Color rules:

- Default text must stay `#f4f4f5` or `text-zinc-50`; supporting text must stay `#e5e7eb`, `text-zinc-300`, or `text-zinc-400`.
- Focus must use cyan focus rings; do not rely on color-only hover state.
- Not-found and empty states are neutral dark surfaces, not red/destructive states.

## Route And Layout Contract

### `/writing` Index

- First viewport must be the actual writing browsing surface, not a marketing landing page.
- Use a compact `.page-intro` with:
  - eyebrow: `Notes and essays`
  - H1: `Writing`
  - lead copy: `Curated notes on agentic engineering, open systems, identity, and practical web software.`
- The writing list must be visible without requiring a large hero scroll on desktop and mobile.
- Render entries from `publicWritingEntries()` in helper-provided order.
- Each writing card must show:
  - title linked to `writingDetailPath(entry)`
  - summary
  - kind label: `Note` or `Essay`
  - visible date label when available: `Published {Month D, YYYY}` or `Updated {Month D, YYYY}`
  - topics and tags as wrapped chips
  - related project count hint when relationships exist, using `1 related project` or `{N} related projects`
  - action link: `Read note` or `Read essay`
- If no public writing exists, render one `.empty-state.visual-surface` with the copy in the Copywriting Contract.

### `/writing/{slug}` Detail

- Use an `<article>` with a single H1 and nested H2 section headings.
- Top of detail page must include:
  - back link: `Back to writing`
  - eyebrow: `Note` or `Essay`
  - H1: entry title
  - lead: entry summary
  - wrapped metadata row with kind, date, topics, and tags
- Render typed body blocks:
  - `paragraph`: body paragraph with 16px / 1.5 line height
  - `list`: unordered list with 16px / 1.5 line height and 16px item gaps
  - `callout`: `.notice-panel.visual-surface` with amber left border and body text
  - `link`: `.text-link.surface-link`; external links must use `rel="noopener noreferrer"` and `target="_blank"`
- Keep reading content max width to the existing `max-w-3xl` or `max-w-4xl` pattern. Do not span paragraphs across the full 6xl shell width.
- Related projects render below the body or in a right-side detail panel using selected project detail cards only. Each related project item must show project name, one-line summary, and `Project details`.
- Omit the related projects section entirely when there are no related selected projects.

### Unknown Writing Slug

- Unknown, draft, hidden, archived-only, or unpublished writing slugs must render a non-leaking fallback.
- Do not show the requested slug, draft title, hidden title, or any private content.
- Use `.page-intro` plus `.primary-action.interactive-surface` with the Copywriting Contract copy.

### Project Detail Related Writing

- Add a `Related writing` panel to selected project detail pages only when public writing references that selected project.
- Derive the list from the writing registry; do not add reciprocal writing fields to project records.
- Each related writing item must show title, kind/date metadata, summary, and a link labeled `Read note` or `Read essay`.
- Omit the panel entirely when no public writing references the selected project.

## Interaction Contract

- Navigation: `/writing` appears in primary navigation as `Writing`; it must be keyboard reachable in tab order.
- Back path: every writing detail page has a visible `Back to writing` link before the H1.
- Card interaction: only links are interactive. Do not make entire cards clickable through JavaScript handlers.
- Motion: `ReactiveSurface` may wrap writing card grids only. Do not add new JavaScript animation for article body content.
- Reduced motion: all decorative hover transforms, pointer glows, and transition effects must remain disabled for `prefers-reduced-motion: reduce`, coarse pointers, and mobile viewports using existing guards.
- Focus: every internal and external writing/project link must show a visible cyan `focus-visible` ring.
- Touch: action links, nav links, and back links must keep a minimum 44px touch target.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Read note` for note cards, `Read essay` for essay cards; fallback and return CTA is `Browse writing` |
| Empty state heading | `No public writing yet` |
| Empty state body | `Published notes will appear here after they are added to the curated writing registry.` |
| Error state | `No public writing here. Return to the writing index to browse published notes.` |
| Unknown slug CTA | `Browse writing` |
| Back link | `Back to writing` |
| Related projects heading | `Related projects` |
| Related writing heading | `Related writing` |
| Destructive confirmation | none; Phase 15 has no destructive actions |

Copy rules:

- Use "published" for public visibility. Do not mention draft, hidden, archived-only, CMS, MDX, RSS, comments, newsletter, or future metadata features in user-facing copy.
- Link labels must identify the destination or action; do not use "click here" or repeated ambiguous "read more" labels.
- Date copy must be human-readable while preserving machine-readable `datetime` values when using `<time>`.

## Verification Contract

Implementation must prove:

- Desktop dark rendering for `/writing`, one public `/writing/{slug}`, and one selected project detail page with related writing when available.
- Mobile dark rendering for the same route set.
- Contrast/readability on body text, chips, links, not-found fallback, callouts, and related item cards.
- No horizontal overflow and no obvious text/control overlap for long writing titles, long tags, and long link labels.
- Keyboard focus reaches primary nav `Writing`, writing card links, detail back link, related project links, and project detail related writing links.
- Reduced-motion mode disables decorative pointer glow and hover lift on writing cards while preserving readable static content.
- Static build output includes `/writing` and public writing detail routes before hydration through route helpers and prerender configuration.
- Draft, hidden, archived-only, unpublished, unknown, or missing writing slugs do not expose private content.

Recommended commands for executor verification:

- `bun run format:check`
- `bun run check`
- `bun run typecheck`
- `bun run test`
- `bun run build`
- `bun run verify:static`
- `bun run verify:browser`

Manual visual inspection must include desktop and mobile dark screenshots or equivalent browser evidence for `/writing` and at least one writing detail page.
