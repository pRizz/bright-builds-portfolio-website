<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem -> freshness parser | Checked-in JSON snapshots, generated manifests, PNG metadata, and built HTML are untrusted boundary data until parsed. |
| built static HTML -> report output | `.output/public` may contain external URLs and query strings that must not leak sensitive values. |
| maintainer CLI -> source tree | The report command runs in the repo and must not mutate curated registries, snapshots, generated assets, manifests, package scripts, or docs. |
| local evidence -> maintainer interpretation | Offline reviewed evidence must not be presented as hosted crawler validation, live external-link reachability, or current live GitHub state. |
