# Phase 32 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

***

## Design System

| Property | Value |
|----------|-------|
| Tool | Mystic UI theme plus repo-local Tailwind CSS utilities. shadcn is not initialized. Source: `package.json`, `tailwind.config.ts`, `src/styles/app.css`. |
| Preset | Not applicable. Use `withMysticUI()` with Tailwind `darkMode: "selector"` and the existing `.dark` root contract. |
| Component library | Mystic UI theme, native HTML controls, and local Solid components (`ReactiveSurface`, `TopicChipList`, existing card/surface classes). Do not add Radix, Base UI, shadcn blocks, or a new component kit. |
| Icon library | None for this phase. Use text labels and native controls; do not add an icon dependency for filtering/search. |
| Font | `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`. Source: `src/styles/app.css`. |

## Phase Surfaces

| Surface | Contract |
|---------|----------|
| `/projects` | Place a compact filter/search surface after the intro and hidden/excluded notice, before the existing grouped project sections. Preserve Flagship, Supporting, Lab / Prototype, Writing, and Archive section behavior for default static content. |
| `/writing` | Place a compact filter/search surface after the intro and before the existing writing cards. Preserve note/essay cards, related-project count copy, topic chips, and `Read note` / `Read essay` actions. |
| Static default | Both pages must render useful public default cards in static HTML before hydration. Filtering progressively narrows those records after hydration. |
| Shareability | Keep filter state in memory only. Do not add query params, hash state, localStorage, sessionStorage, sitemap routes, canonical changes, or crawlable faceted URLs. |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Label-to-control gaps, inline metadata spacing, compact count separators. |
| sm | 8px | Facet option gaps, chip gaps, control row gaps, card internal micro-spacing. |
| md | 16px | Default fieldset spacing, input-to-facet spacing, card content rhythm. |
| lg | 24px | Filter surface padding, empty-state padding, grouped control spacing. |
| xl | 32px | Gap between filter controls and results, writing list top gap. |
| 2xl | 48px | Major page section breaks on dense discovery pages. |
| 3xl | 64px | Page-level spacing and scroll-margin style offsets. |

Exceptions: minimum interactive target is 44px via existing `min-h-11` / `min-w-11` patterns for search inputs, checkbox labels, links, and the reset button.

## Typography

Use exactly these four sizes and only weights 400 and 600 for new Phase 32 UI.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.25 |
| Display | 36px | 600 | 1.15 |

Typography constraints: no negative letter spacing, no viewport-based font sizing, and no hero-scale text inside filter panels. Labels, facet names, and counts must wrap without clipping on mobile.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#050608` | Page background, input fill, deepest control surface areas. |
| Secondary (30%) | `#18181b` over `#0d1117` | Cards, nav, filter surface, empty states, chips, grouped panels. |
| Accent (10%) | `#6ee7b7`; focus-only accent `#67e8f9` | Selected facets, topic links, primary reset action, count emphasis, focus-visible rings. |
| Destructive | `#f87171` | Destructive actions only. Phase 32 has no destructive actions, so this should not appear in the filter UI. |

Accent reserved for: selected filter state, topic chip links, result count emphasis, `Reset filters`, hover/focus affordances, and cyan focus-visible rings. Do not use accent color as a broad decorative wash across every control.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Reset filters` |
| Empty state heading | Projects: `No public projects match these filters` / Writing: `No public writing matches these filters` |
| Empty state body | Projects: `Clear filters to return to the full curated project index.` / Writing: `Clear filters to return to all public notes and essays.` |
| Error state | `Filtering is unavailable. The default public content is still visible; refresh the page or clear filters.` |
| Destructive confirmation | None: Phase 32 must not add destructive actions. |

Additional control copy:

| Surface | Required Copy |
|---------|---------------|
| Project search label | `Search public projects` |
| Writing search label | `Search public writing` |
| Project count status | `{visible} of {total} public projects shown` |
| Writing count status | `{visible} of {total} public writing entries shown` |
| Project facet legends | `Topics`, `Tier`, `Status`, `Source` |
| Writing facet legends | `Kind`, `Topics`, `Tags`, `Year` |
| Project source labels | Use visitor-facing labels such as `Original`, `Fork / promoted work`, and `Prototype / playground`; do not expose internal taxonomy names. |

## Interaction Contract

| Interaction | Contract |
|-------------|----------|
| Search | Use native `input type="search"` with a visible label. Placeholder text is optional and must not be the only label. |
| Facets | Use native fieldsets with legends and checkbox controls by default. A native select is acceptable only for long date/year lists if it improves mobile layout. Avoid custom ARIA widgets. |
| Result status | Render a visible count and expose it with `role="status"` and `aria-live="polite"`. Announce only result-count changes caused by filter/search state. |
| Reset | Render an explicit `Reset filters` button with a 44px minimum target. It must clear search text and selected facets and restore the original public order/grouping. |
| Keyboard | Tab order must be search input, facet controls in visual order, reset button, then results. Focus-visible state must use the existing cyan ring pattern. |
| Touch/mobile | Controls must stack or wrap cleanly at 320px width. No desktop facet rail, no nested cards, no overlapping labels, and no clipped long topic/tag/source labels. |
| Empty results | Show one clear empty state for the page when no public record matches. Do not imply hidden, draft, or excluded content exists. |
| Topic journeys | Topic chips remain the durable share path and must continue to resolve through canonical topic helpers. Filters must not fabricate topic routes from raw labels. |

## Layout and Component Contract

| Area | Contract |
|------|----------|
| Filter surface | Use a single `.visual-surface`-style panel with `border-white/10`, dark gradient surface, 8px max radius, 24px padding, and responsive internal wrapping. Do not place a card inside another card. |
| Inputs | Use dark input backgrounds, visible borders, 44px min height, 6px to 8px radius, 16px horizontal padding, and existing cyan focus rings. |
| Facet options | Use compact checkbox rows or wrap-safe checkbox chips. Each option label must be readable as text, not just color. Selected state uses emerald accent plus border change. |
| Project results | Default state preserves the existing grouped sections and section counts. Filtered state may hide empty sections, but a no-match page state must be a single empty panel. |
| Writing results | Preserve the current responsive writing card grid and card content hierarchy. Do not introduce a sidebar, dashboard, or flat curation table. |
| Motion | Reuse existing reactive-surface/card effects only where already present. Reduced-motion, coarse pointer, and small viewport rules must keep filter controls still and readable. |
