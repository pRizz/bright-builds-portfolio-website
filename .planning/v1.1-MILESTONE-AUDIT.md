## Gap Details

### Clean Builder Playwright Provisioning

**Affected requirements:** `BROW-01`, `GATE-04`, `REL-03`, `REL-04`

`bun run verify` is the aggregate release gate and includes `verify:browser`. That browser gate needs a Playwright browser binary. Phase 6 recorded that Chromium had to be installed locally with `bunx playwright install chromium`, but current release docs and package scripts do not document or automate that prerequisite for clean builders. The Cloudflare/static release path therefore may fail before it can prove the milestone's browser and deploy-readiness guarantees.
