## Trust Boundaries

| Boundary | Description |
| --- | --- |
| checked-in route content -> generated public PNGs | Public project, writing, theme, and index route text becomes share-card image content. |
| social preview target asset path -> local filesystem | `/social/generated/...` web paths become writable files under `public/social/generated/`. |
| SVG template text -> resvg renderer | Curated copy is interpolated into XML/SVG and then rasterized by a native dependency. |
| generated PNGs + manifest -> static deploy artifact | Checked-in files are copied into `.output/public` and later crawlers can request them. |
| maintainer CLI -> local environment | The generator runs on a developer or clean-builder machine but must not read secrets, make network requests, use runtime services, or add runtime endpoints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-25-02 | Information Disclosure | `scripts/generate-social-previews.ts` target inventory | mitigate | Verify manifest asset paths exactly equal `socialPreviewTargets()` and no extra/orphan managed PNGs exist. |
| T-25-03 | Tampering | `scripts/social-previews/template.ts` SVG interpolation | mitigate | Use Plan 25-01 tests and generated-render verification; this plan does not alter template code. |
| T-25-04 | Repudiation | `public/social/generated/manifest.json` | mitigate | Commit sorted timestamp-free manifest with `sourceFingerprint`, `byteSize`, and SHA-256 checksum for every generated preview; check mode compares rerendered files and manifest. |
