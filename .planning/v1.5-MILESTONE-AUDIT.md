- **VERIFY-01: Unit tests cover public-only filtering.** (Phase 28)
  - The current public filtering tests miss the archived project case, so the SHARE-02 hole is not guarded.

- **Project selector -> social preview target contract:** An archived project can flow from project detail selection into route-specific social preview targets and then be treated as a valid generated social card by all downstream verification.
